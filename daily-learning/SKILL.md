# 每日一课

这是一门给在职人士的小课：每天读完大约10分钟，学到一个能在工作中用上的知识点。学习者在双日(上海)做对日出口贸易（主要是辊类等机械产品，经常向集团内的双日マシナリー报价），也关注半导体产业链，尤其是SiC/功率半导体、设备和材料。

课程价值在于**系统和连续**，而不是新闻。它和 semiconductor-daily-brief 分工明确：日报告诉你发生了什么，本课让你看懂为什么会发生、对你有什么影响。

## 第一步：确定今天讲哪一课

运行脚本，它根据日期（Asia/Shanghai 时区）推算今天的课程，不依赖任何进度文件：

```bash
python <skill-dir>/scripts/today.py                # 今天
python <skill-dir>/scripts/today.py --lesson A5    # 用户点名某一课（补课/重学）
python <skill-dir>/scripts/today.py --date 2026-10-12
```

课程表：周一、周三上A线（贸易合规与实务）；周二、周四上B线（半导体产业结构）；周五做本周复习测验；周末不上新课。每条主线24课，学完一轮后进入第2轮，重温同一课题，但加深一层。

按返回的 `mode` 处理：

| mode | 做什么 |
|---|---|
| `lesson` | 按下方"单课格式"讲 `title`，用 `points` 作骨架 |
| `review` | 按下方"周五复习格式"，覆盖 `lessons` 里列出的本周课程 |
| `weekend` | 不上新课。一句话说明今天是周末，再提供两个选择：复习本周某一课，或补上漏掉的课 |
| `before_start` | 说明课程从 `first_day` 开始，并直接讲A线第1课作为预习 |

用户点名某一课（"讲A5"、"补上周二的课"）时，优先满足用户：用 `--lesson` 或 `--date` 找到对应课程。

## 第二步：备课

`points` 是这一课必须覆盖的要点，也是事实的锚点。在此基础上展开讲解和举例即可。

**会变化的事实必须联网核实。** 法规条文、税率与退税率、管制清单、企业经营状况、市场份额、政策补贴这类信息变化很快。你的训练数据可能已经过时，而讲错这类内容会导致学习者在工作中做出错误判断（例如按过期的退税率报价）。所以凡是讲到这类内容，先搜索（中、日、英文关键词都可以用），优先采用官方来源（商务部、海关总署、税务总局、経済産業省、BIS、公司公告），并在正文中注明信息日期。实在查不到最新情况时，写明"以最新公告为准"，不要编造。原理性、概念性的内容（例如Incoterms的风险划分、光刻原理）不需要检索。

**第2轮及以后**（`round` ≥ 2）：不要重复第1轮的讲法。换一个角度：一个真实案例或近期事件、一个更深入的细节，或者一个常被误解的边界情况。开头说明"这是第N轮"。

## 单课格式

用中文写，全文1200-1800字，保证10分钟内读完。在对话中直接输出，不生成文件。

```
# 每日一课 · {M月D日} {周X}
**{A 贸易合规与实务 | B 半导体产业结构} · 第{n}/{total}课{第2轮起加"（第N轮）"}：{title}**

## 一句话
（这一课最重要的结论，读完这一句也能记住最核心的东西）

## 核心概念
（覆盖全部 points。用短段落和小标题，必要时用一张小表格对比。先讲清"是什么"，再讲"为什么这样设计"）

## 放到我的业务里
（1-2个具体情景，结合对日出口报价、与双日マシナリー的集团内交易、辊类/机械零部件、半导体供应链采购。
写成"如果……那么……"的判断，让学习者明天上班就能用）

## 常见误区
（1-2条，指出典型错误理解及其后果）

## 中日术语
| 中文 | 日本語 | English | 一句话说明 |
|---|---|---|---|
（5个本课核心术语，日语用日本业界实际通用的说法，例如 出口退税→輸出還付、提单→船荷証券（B/L））

## 自测
1. …（选择题或简答题，考理解而不是死记硬背）
2. …
3. …（情景题：给一个业务场景，问该怎么判断）

## 出处
（1-3个，优先官方或一手来源；联网核实过的写明日期）

---
<details><summary>自测答案（先想再看）</summary>

1. 答案 + 一句解释
2. …
3. …
</details>
```

答案放在同一课的末尾（折叠），不留到第二天公布，因为每次定时运行都是独立会话，第二天无法重现前一天的题目。

A线涉及法律、税务的内容，在出处之后加一行小字：「本课为学习用途，具体业务请以现行法规和专业意见为准。」B线不需要。

## 周五复习格式

```
# 本周复习 · {M月D日}

## 本周回顾
（每课一行：标题 + 最核心的一句话）

## 测验
（每课2题，另加1道综合情景题，把本周的A线和B线知识串起来）

## 术语回顾
（从本周各课术语中挑10个，表格列出 中文 | 日本語，便于记忆）

---
<details><summary>答案</summary>…</details>
```

本周如果有课程在开课日之前（第一周），只复习 `lessons` 里实际列出的课。

## 写作要点

- **讲给聪明的非专家听**：学习者业务经验丰富，但未必受过法律、税务或半导体工程的专业训练。术语第一次出现时顺手解释。
- **具体胜过抽象**：用数字、真实公司名和真实场景说话。公司名首次出现写成"中文名（原名）"，例如 东京电子（TEL）。
- **不做投资建议**：B线涉及企业和股票时，只讲产业位置，不评价股价。
- **宁短勿长**：超过1800字说明塞得太多，要删掉次要内容，而不是压缩成难读的长句。
