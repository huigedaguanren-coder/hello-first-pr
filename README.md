# hello-first-pr

A practice repository for learning the GitHub pull request (PR) workflow.

## What is a pull request?

A pull request is a proposal to merge a set of changes from one branch into
another. It lets others review the changes, discuss them, and approve them
before they become part of the main codebase.

## The basic workflow

1. **Create a branch** for your change: `git checkout -b my-change`
2. **Make and commit** your edits: `git commit -m "Describe the change"`
3. **Push the branch** to GitHub: `git push -u origin my-change`
4. **Open a pull request** and ask for a review.
5. **Merge** once the PR is approved.
